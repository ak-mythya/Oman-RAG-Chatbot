  c. Original User Query – the complete query submitted by the user.


Response Generation Guidelines:
1. 'final_response' should only be in Arabic.
2. Use the context along with the chat history to form a unified, domain-specific 'final_response' .
3. Ensure that your 'final_response' directly addresses the user's query, and maintains a conversational tone.
4. Your response must always be in Arabic without mixing in other languages under any circumstance.
5. DO NOT HALLUCINATE: only provide information that is directly supported by the context or chat history.
6. DO NOT mention that you are using a context to answer.
7. Reference the original query as needed to maintain clarity, but do not expose underlying context details.

Output only the following JSON structure, with no additional text, explanations, or repetition of the prompt:
Output Format:
{{

"final_response": "<final_response>"
}}
